# Bharat Internet Doctor — Security Workspace

A privacy-first static cyber-safety workspace. It combines local URL structure review, IPv4 CIDR calculations, a temporary blocklist draft, a user-reviewed incident-notes helper, and optional approximate public IPv4 region lookup.

## Run

Open `index.html` in a modern browser or serve this directory as static files. No build step, backend, dependencies, API key, or GPU is required.

## Features and boundaries

- **URL/IP review:** Parses HTTP(S) URL/domain/IPv4 inputs in-browser and shows limited structural heuristics. It does not open/fetch targets, query WHOIS/DNS/reputation feeds, scan ports, or establish that a target is safe or malicious.
- **Optional location:** After explicit confirmation, a public IPv4 literal is sent to `ipwho.is` for approximate region and ASN/ISP data. The provider may receive the query IP. Data can be stale or inaccurate and does not identify a person. Domains and private/local IPv4 addresses are not sent.
- **Network map:** Calculates IPv4 CIDR boundaries locally. It does not probe networks or discover devices.
- **Firewall draft:** Holds IPv4 entries/CIDRs in page memory and allows manual copying. It does not enforce firewall rules. Review scope and evidence before applying anything to systems you administer.
- **Incident helper:** Creates a local, human-reviewed note draft. It does not email or submit reports.
- **Alerts:** In-page notifications are generated by actions in the open tab only. No push, service worker, scheduled task, or background monitoring exists.

No cookies, analytics, login, database, external scripts, or browser persistence are used. Inputs and drafts stay in memory and disappear when the page is reloaded or closed. The optional region lookup is the only feature that transmits a user-entered indicator to a third party. Hosting providers may independently process standard request metadata.

A website cannot silently inspect device files, remove malware, or provide 24/7 endpoint protection. Use trusted endpoint security software installed with the device owner's consent. IP geolocation is approximate, not precise person-location or attribution. Never block or accuse based solely on a heuristic or location result. For India cybercrime reporting, use the official [National Cyber Crime Reporting Portal](https://cybercrime.gov.in/); for financial cyber fraud, contact your bank and call 1930 promptly.
